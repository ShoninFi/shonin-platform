What Shonin was

Smart contracts are public and auditable. Trading agents should be too.

Shonin was the open platform for verifiable trading agents. Depositors pooled their money in vaults, and each vault's agent ran in an attested machine that proves which build it runs, with keys that could only move money between the vault's own accounts.

Depositors could back agents they could actually check. Authors could earn a share of the profit a good agent made, without ever holding anyone's money.

Carry it forward

Want to take Shonin further? Write to us.

The code is public and the documentation is complete: the contracts, the attested machines, the app and the agents. Each repository's licence says what it may be used for. If you'd like to carry it forward, we'd like to hear from you.

What was built

Four pieces, each written up in full

All of it ran on test networks, and all of it is in the docs and the code.

  • {{i:machine:22}}

    Attested execution, trade-only keys

    Agents ran in attested machines on Google Cloud that prove which build they run, signing with keys that could place and cancel orders, and nothing else.

    How attested machines work{{i:arrow:18}}
  • {{i:review:22}}

    An AI review of every agent, published

    A model read all of an agent's code before it was built, sealed code included, and its report was public for anyone to read.

    How the AI review works{{i:arrow:18}}
  • {{i:vault:22}}

    Vaults and stations on four test networks

    Money only moved between a vault and its own stations on the other chains it traded.

    • Base Sepolia
    • Hyperliquid's testnet
    • Robinhood Chain's testnet
    • Solana's devnet
    How the contracts work{{i:arrow:18}}
  • {{i:code:22}}

    Agents in Rust, compiled to WebAssembly

    Anyone can rebuild an agent from its source with the published recipe and get the fingerprint the chain holds.

    How to verify a build{{i:arrow:18}}

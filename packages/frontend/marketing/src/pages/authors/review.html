The review

What the Reviewer checks

Before anything is built, an AI Reviewer reads all of your code and rates it in six areas. The report is public, and it's tied on the chain to the exact code that will run.

  1. 01

    Security

    Whether the code tries to leak secrets, reach places it shouldn't, or harm the vault.

  2. 02

    Financial risk

    How much the strategy could lose: leverage, position sizes, and what it does in a fast market.

  3. 03

    Reliability

    Whether it keeps working through restarts, dropped connections and venue errors.

  4. 04

    Reproducibility

    Whether the same source always builds the same program, so anyone can check the build.

  5. 05

    Outside influence

    Whether anything outside the code, like a server, a data feed or a model, could steer its trades.

  6. 06

    Accurate description

    It checks your description and every claimed limit against the code.

Each area gets one of four ratings

  • {{i:check:14}}Looks fineNothing in this area worried the Reviewer.
  • {{i:concern:14}}Some concernsWorth reading before depositing. The report says why.
  • {{i:serious:14}}Serious concernsA real problem. Depositors see it at the top of your page.
  • {{i:unknown:14}}Couldn't tellThe code alone wasn't enough to judge.

{{i:info:20}}Only malicious code is refused. Everything else is published with its ratings, good or bad. A review is advice, not a prediction: it never rates how much an agent might make.

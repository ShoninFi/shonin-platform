The template

Get started in four commands.

The template is a working agent with tests. Change the strategy, keep the shape.

When it does what you want, submit it on the Publish page and pay 1 USDC.

What's in the template
FileWhat it's for
shonin.tomlName, description, claims, vault chain and drivers. Fixed once published.
src/config.rsYour settings and limits, in one place.
src/lib.rsThe long-lived program: watches the markets and hands orders on.
src/decide.rsYour strategy, as a pure function that's easy to test.
tests/Tests for the strategy. cargo test runs them.
Cargo.toml
Cargo.lock
rust-toolchain.toml		Pinned dependencies and toolchain, so anyone can rebuild it and get the same program.

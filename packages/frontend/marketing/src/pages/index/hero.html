{{i:concern:18}}Agents can lose money. Nothing here stops that. What can still go wrong

  • {{i:seal:24}}

    Attested machines. The machine proves which build it runs. Only the build that was reviewed can trade the vault, and nobody can swap it.

  • {{i:key:24}}

    Trade-only keys. The keys that trade can place and cancel orders, and nothing else. No key can withdraw your money.

  • {{i:bridge:24}}

    One vault, many chains. An agent can trade across chains from a single vault, and its money only moves between that vault and its own stations.

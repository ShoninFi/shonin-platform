For Traders

Know what an agent will do before you back it.

Most automated strategies ask you to trust a pitch. Here you read a review of the actual code, and the chain makes sure that code is what's trading.

  1. {{i:review:22}}

    Read what it will do

    Every agent comes with a public review of its code: a plain summary, and ratings in six areas from financial risk to outside influence.

  2. {{i:check:22}}

    Know it does what it says

    The Reviewer checks the Author's description, and every limit they claim, against the code itself. A promise the code doesn't keep counts against the agent.

  3. {{i:seal:22}}

    It can never be swapped out

    Only the exact build that was reviewed can trade the vault. A changed agent is a new agent, with a new vault, and nobody is moved into it.

  4. {{i:code:22}}

    Read the source yourself

    If the Author made it public, read every line, then rebuild it and get the same fingerprint the chain holds.

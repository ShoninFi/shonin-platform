## Is it really the agent I chose?

Only keys made inside an enclave, for this exact agent, can trade for its vault. Our contracts check every key before it can act, and every order has to come from one of them.

For convenience, every vault's page shows the public address of each of its keys, so you can look them up on the chain yourself.

## Is the code what it claims?

If the source is public, you can build it yourself and get the same fingerprint the chain has on record. That proves the code running is the code you just read.

If the Author sealed it, you can't read it, but the Reviewer can. It reads the source on an attested machine before anything is built, and its report is public. The chain records exactly which source it read, so you can check that the report is about the code that's running.

## Could you slip in keys of your own?

No. There's no way to add a key by hand. Our contracts accept a key only with an attestation, and the part that checks attestations is fixed when the contracts are deployed, so nobody can swap it for a more forgiving one later.

Our own admin key can't get around it either. It can do only two things: take a machine image off the approved list, or add one, which only counts after a public two-day wait. So the list is the thing to watch: every image on it can be rebuilt from published source, and the wait gives anyone time to check a new one before it's used.

Every key's record on the chain shows which image made it, and the transaction that proved it.

## Are the returns real?

Yes, the vault's contract works out its own value from what it holds, and every trade it makes is a public record. Look up any number on the site and you'll get the same answer from the chain.

## Can I get out without you?

Yes. Even if everything we run went dark tonight, you could withdraw by going to the vault's contract directly.

If there's enough cash in the vault, you're paid straight away. If not, the contract books your withdrawal and closes your share of its positions, and anyone, including you, can push it through. We're not in the way.

The one exception: a few vaults trade somewhere the contract can't reach on its own. Those need an operator to finish, and their page tells you so up front.

## What checking can't tell you

**Whether the agent is any good.** Careful code can still lose money. The review reads the code, but nobody can promise results.

**Why a trade happened.** The chain shows every trade, but not who was on the other side or why. A trade at a bad price still moves money, which is the risk explained on [Trade-only keys](basics/trade-only-keys.md).

**That the hardware is honest.** Attestations are signed by the chip's maker. If a maker's chips were broken, attestations could be faked, and nothing on the chain would show it.

**What happens next.** A track record is history. It shows how an agent did, at its size, in the markets it saw, not how it will do.
